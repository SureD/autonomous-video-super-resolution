# Experiment template

Copy this folder to `experiments/YYYYMMDD-short-name/`.

Required files:
- `config.yaml` — hyperparameters, model, data, precision
- `env.md` — OS, GPU, driver, CUDA, PyTorch, TensorRT versions
- `results/` — raw metrics CSV/JSON (no fabricated numbers)
- `notes.md` — protocol, observations, links to STATUS.md hypotheses
