**Closest prior and defensible gap.** Meta-KD (2022) already adapts transferred information to the student's features, receptive field and aptitude. MTKD already fuses teachers; RTSR already uses two fidelity/perceptual teachers for real-time compressed content; Selective Diffusion Distillation already rejects uncertain SR teacher guidance; FlashVSR already distils a temporally richer teacher into a causal VSR student. Combining these ingredients is at best incremental. A narrower unresolved claim is: *an explicitly tested proxy for detail predictable from the exact causal student input and receptive field improves reconstruction beyond teacher reliability, generic difficulty weighting and student-conditioned Meta-KD*. None of the opened papers establishes that exact comparison. Absence from this search is not proof of novelty.

**The conceptual trap.** Teacher disagreement estimates teacher reliability/diversity. Reference-derived visibility describes whether a reference correspondence is valid. Neither measures whether the student's limited prefix, local receptive field and capacity can infer the detail. Two teachers can confidently agree using future frames that the student never receives. Conversely, disagreement can occur on recoverable detail. A visibility mask is useful for valid supervision but cannot itself justify “resolvability-aware.”

**Falsifiable remainder.** Compare a causal-input predictability proxy with uniform KD, each teacher alone, confidence/visibility weighting, texture/confidence/error-matched shuffled weights, teacher-error weighting and Meta-KD. Cross-fit both the student probe and the weight regressor by source clip. Keep GT reconstruction everywhere, count auxiliary training cost, and test motion/disocclusion subsets with spatial guardrails. The [agenda](03-research-agenda.md) specifies the arms and estimator; its cheap texture-statistic regressor is a limited difficulty baseline, not a demonstrated observability model. An anti-causal probe is a possible later diagnostic, not an implemented arm or supporting evidence here.

**Theoretical limit.** For student input X and full-context teacher target Z, squared matching has irreducible `E Var(Z|X)`. Teacher agreement cannot remove unavailable information. Input-only weights cancel from the unrestricted conditional optimum; reference/future-dependent weights can shift it. A finite student may benefit from reallocating errors, but theory alone predicts no quality gain. Identical LR prefixes with different HR targets provide a CPU falsification fixture; see document 03.

### What remains testable

The defensible claim is narrow: **under identical one-frame compressed-input marginals, correlated codec states improve deployed temporal reconstruction through a training-only temporal objective, including unseen GOP structures.** This is an interaction claim, with unchanged single-frame inference graph. It is not a claim that H.264 augmentation, full-sequence encoding, causal VSR, or realistic degradation training is new.

There is a useful theoretical null. For a stateless image student and separable objective,

\[
L(\theta)=\sum_t\ell(f_\theta(x_t),y_t),
\]

permuting the same paired samples leaves the objective and full-batch gradient unchanged. If frame marginals are matched, expected objectives also match. SGD order/batch effects may differ but do not establish learning from temporal codec coherence. Current repository models and ordinary Charbonnier training are in this regime. A CPU permutation-gradient fixture can settle this before GPU training. A temporal loss involving separately evaluated adjacent outputs can make coherence identifiable while preserving the inference graph; a causal multi-frame graph is another option but needs a fresh latency gate.

### Identifying the coherence mechanism

Use full clips and encode before cropping. For every source index store several independently encoded versions. Coherent windows use one encode state throughout; stitched windows select states independently at the same source indices. Uniform balanced usage matches one-frame marginals while preserving clean motion. A **coherent/stitched × temporal loss off/on** factorial isolates the interaction at an unchanged single-frame inference graph. Framewise encoding and bicubic-only training are additional H3 controls with different marginals. Exact arms, seeds, GOP/codec holdouts, temporal metrics and stop rules are in the [agenda](03-research-agenda.md).

The off contrast is a theoretical null, apart from optimization-order effects. Whole-pair shuffling would also destroy clean motion in a temporal objective, so it cannot isolate artifact coherence. Same CRF does not match distortion distributions. A gain only on the training codec/GOP is adaptation, not transferable temporal learning. Stitched state changes are intentionally artificial; that limits production-stream extrapolation.

**Closest prior and exact distinction.** With branch parameters θ and equivalent kernel K(θ), the forward path `Conv(Qa(x), Qw(K(θ)))` is RepQ. `sum_i Conv(Qa(x), Qw(K_i(θ)))` generally computes a different integer-grid function because quantization does not commute with merging; products in sequential branches create further mismatch. Post-merge QAT optimizes K directly; RepQ optimizes θ through K(θ). This is an established optimization-parameterization comparison. New penalties need those controls.

The [official RepVGG repository](https://github.com/DingXiaoH/RepVGG) was also opened: its Quantization/Solution B recommends constraining the equivalent kernel, and its custom L2 regularizer acts on equivalent central coefficients. This is implementation evidence, not an extra 2022–2026 paper. The [official ECBSR repository](https://github.com/xindongzhang/ECBSR) was opened and confirms the 2021 foundation and its single-Y-channel original training; the present RGB adaptation is not an exact reproduction. ECBSR’s ACM paper itself could not be opened, so detailed paper-specific claims beyond opened RepQ/official code are **unverified**.

**Useful deployment replication.** Only after measuring a real export drop, compare equal-step ordinary FP32 finetuning, post-merge QAT, and RepQ from matched pretrained functions, with fixed calibration data/quantizers and actual TRT outputs/latency. Add a new regularizer as RepQ versus RepQ+regularizer. Branch-space QAT is diagnostic because it need not simulate the merged integer function. Current ECB has no BN: identity-BN-outlier explanations from QARepVGG/OABN cannot be presumed. See document 03, G2.

## Coverage and interpretation limits

RTSR, MTKD, SPAN, RepSR, BasicVSR++, RealBasicVSR, AnimeSR and recent efficient/real-time challenge methods are represented above. **ECBSR (2021)** is an older foundation: its official code and the opened RepQ paper support the stated deployment/quantization relevance; the original paper remained inaccessible. **“EDVR-lite” is unverified as a unique paper/configuration**: searches did not identify a canonical 2022–2026 primary paper under that name. Do not invent a lightweight EDVR citation or import latency from an unspecified variant. A named code configuration could become a comparator after its exact graph and causal window are documented and measured.

The NTIRE 2023 real-time 4K report was found but direct CVF abstract/PDF opens both failed (403); its search-index text is excluded as evidence. The 2024–2026 opened reports provide contemporary efficient baselines instead. Access errors and abstract-only papers weaken any claim that an exact mechanism has never appeared. All unresolved source URLs are in the section access ledgers; failed mirrors with a successful alternate opening are distinguished from papers whose text was never opened.
